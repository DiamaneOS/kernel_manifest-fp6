# DiamaneOS kernel manifest for Fairphone 6

Repo manifest pinning every source of the DiamaneOS Fairphone 6 kernel: the
Fairphone kernel platform, the GrapheneOS common kernel and the DiamaneOS
forks of the Qualcomm vendor kernel and driver modules.

`default.xml` is generated by DiamaneOS tools from its kernel source plan
(`config/kernel-sources-fp6.json` and `config/patches.json`). Do not edit it
by hand; regenerate it with `diamaneos kernel manifest --output default.xml`.

## Building

With [DiamaneOS tools](https://github.com/DiamaneOS/tools) on `PATH`:

```sh
repo init -u https://github.com/DiamaneOS/kernel_manifest-fp6 -b main
repo sync -c
diamaneos kernel prepare --workspace .
diamaneos kernel build --workspace .
```

`kernel prepare` checks every project against the source plan, verifies the
fork changes and creates the workspace links a manifest cannot express.
Once a kernel is accepted, Android builds will use prebuilt kernels published
in [device_fairphone_FP6-kernels](https://github.com/DiamaneOS/device_fairphone_FP6-kernels)
and will not need this tree.
